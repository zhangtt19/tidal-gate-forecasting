# 怎样用三分钟介绍这个作品

**30 秒介绍**

我以前研究潮汐影响下的港闸流量，完成了一篇第一作者论文和伴生专利工作。原来通过工程软件的神经网络模块做研究；现在我把它整理成一个可运行的 Python 项目，重点展示真实数据处理、物理与机器学习结合，以及独立验证。

**我实际做了什么**

原研究由导师提出思路，我负责数据清洗、特征与参数试验、分析和成果材料。本项目新增可检查的 Python 实现，AI 协助编程与整理；原商业软件不是我编写的。

**两个任务**

一个是在当前水位已知、当前流量待估计时，用历史流量和神经网络修正过流系数，再代入物理公式。另一个是只给过去 12 次观测，预测下一次流量。二者所知道的信息不同，所以我分开验证。

**怎么证明不是只会把模型跑通**

我把 2003 年和 2006 年分开，训练时不使用测试年的数据。除了神经网络，还放入简单的线性模型、固定系数和最近一次观测作为基准，并用自动测试检查未来数据不能进入输入。

**结果不全是正面的**

混合模型比固定系数公式更好，但不是每个站都比最近一次流量更好。12 步预测在这个跨年份测试中也没有超过简单基准。这说明观测跨度、闸门运行变化和任务定义很重要，不能把高拟合精度当作上线后的预报能力。

**迁移能力**

这套数据清洗、特征时间管理、基准比较和可复现评估方法，也适用于环境监测、传感器数据和其他工业时序问题。它不证明我已经熟悉这些行业的全部业务。
