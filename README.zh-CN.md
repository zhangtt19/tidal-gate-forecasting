# 潮汐河段港闸流量动态趋势预测

**利用有限水文观测构造时序变化特征，以 BP 神经网络预测动态出流系数，改善潮汐港闸的流量计算。**

[English](README.md) · [论文](https://doi.org/10.3390/w17091248) · [专利公开文本](https://patents.google.com/patent/CN119578220A/zh) · [方法详解](docs/METHOD.md) · [完整结果表](docs/PUBLISHED_RESULTS.md) · [论文全部图](docs/PAPER_FIGURES.md)

本项目展示张天舒第一作者论文 *Research on Dynamic Trend Prediction Method for Flow Discharge Through Harbor Gates in Tidal Reaches*（Water，2025）及伴生专利中的研究方法、参数配置与结果。研究对象为江苏里下河地区的射阳河、黄沙港、斗龙港和新洋港四座港闸，采用 2003 年及 2006 年的水位与流量观测。

## 研究问题

潮汐顶托和闸门启闭会使水位—流量关系随时间变化。相近的闸上、闸下水位，不一定对应相同的过流状态；传统堰流计算难以充分反映这种非恒定流过程。

本研究在已有水位、流量记录中提取变化趋势，用神经网络学习随工况变化的淹没出流系数，再通过堰流公式计算流量。重点考察总体流量过程，以及开关闸瞬间等快速变化工况。

## 从原始观测到 6 项模型输入

原始记录包含测流时间 $t$、闸上水位 $Z_u$、闸下水位 $Z_d$ 和实测流量 $Q$。时间用于计算相邻记录的变化率；流量用于构造流量变化率及训练目标。

| 模型输入 | 含义 | 提供的信息 |
|---|---|---|
| $Z_u$ | 闸上水位 | 当前上游水位条件 |
| $Z_d$ | 闸下水位 | 当前下游水位条件 |
| $\partial Z_u/\partial t$ | 闸上水位变化率 | 上游水位上升或下降的方向与速度 |
| $\partial Z_d/\partial t$ | 闸下水位变化率 | 下游潮位变化趋势 |
| $\partial(Z_u-Z_d)/\partial t$ | 上下游水位差变化率 | 驱动过流的水位差如何变化 |
| $\partial Q/\partial t$ | 流量变化率 | 过流过程的动态趋势 |

这套输入构造方法把静态水位条件与动态变化信息结合起来，不需要为每一项特征增加一种传感器。变化率的计算需采用实际时间间隔，并统一时间单位。详见论文 §3.2、Tables 2–3。

## 方法流程

```mermaid
flowchart LR
    A[水位、流量与测量时间] --> B[构造两项水位与四项变化率]
    A --> C[利用堰流公式反算历史出流系数]
    B --> D[训练 BP 神经网络]
    C --> D
    D --> E[预测后续时刻的淹没出流系数]
    E --> F[结合水位与闸门几何条件计算流量]
```

网络的直接输出是淹没出流系数 $\hat\phi$。流量由以下关系得到：

$$
\hat Q=\hat\phi B H_s\sqrt{2g(Z_u-Z_d)},\qquad H_s=Z_d-Z_0
$$

其中，$B$ 为闸门开启总宽度，$Z_0$ 为闸底高程，$g$ 为重力加速度。论文以斗龙港的 $B=80\,\mathrm{m}$、$Z_0=-3\,\mathrm{m}$、$g=9.8\,\mathrm{m/s^2}$ 说明计算过程。训练时由实测流量反算系数，并按论文定义与后续时刻的目标系数配对；应用时需确定目标时刻的水位及闸门几何条件。

## 总体结果

与传统堰流公式相比，动态趋势预测方法（DTPM）在论文所研究的四闸资料上改善了计算流量与实测流量的一致性。

| 年份 | 平均相关系数：传统方法 → DTPM | 平均相对误差：传统方法 → DTPM |
|---|---|---|
| 2003 | 0.22 → 0.81 | 16.42% → 3.00% |
| 2006 | 0.35 → 0.82 | 9.73% → 1.32% |

来源：论文 Table 7。相关系数与下图的 $R^2$ 为不同指标；详细站点结果见[完整结果表](docs/PUBLISHED_RESULTS.md)。

五折交叉验证中，斗龙港、黄沙港、射阳河、新洋港的平均相对误差分别为 **5.96%、6.43%、13.95%、9.57%**（Table 5）。论文以交叉验证误差、标准差和过程误差带评价表现，未报告指定置信水平的置信区间；这些指标分别列于[结果说明](docs/PUBLISHED_RESULTS.md)。

## 开关闸瞬间的表现

开关闸瞬间水力条件变化快，仅观察整体拟合可能掩盖局部误差。本研究单独提取斗龙港与新洋港的启闭时刻进行比较，并进一步分析高水位、低水位、快速开闸与缓慢开闸四类工况。

![论文图 10：开关闸时刻的流量过程与误差带](assets/paper/figure-10.png)

- 在 Table 8 列出的启闭样本中，斗龙港最大绝对相对误差由 **24.06% 降至 7.80%**；新洋港由 **176.88% 降至 28.28%**。
- 新洋港传统方法误差为 **176.88%** 的同一条样本，DTPM 的绝对相对误差为 **14.06%**。
- 低水位工况下，新洋港平均相对误差由 **27.95% 降至 4.86%**；缓慢开闸工况下，斗龙港由 **12.49% 降至 2.68%**（Table 9）。

改善并非发生在每一个启闭样本上；[完整结果表](docs/PUBLISHED_RESULTS.md)保留了全部 12 条样本及四类工况，便于查看具体表现。

## 这项方法适合怎样的应用？

面向已具备水位、流量及时间序列观测，并能够使用 BP 等学习模型的水文水力研究者和工程人员，本研究提供了三个可借鉴的环节：

1. **扩充输入信息：**从有限观测中构造具有物理意义的变化率特征，使模型同时识别状态与变化趋势。
2. **连接数据模型与物理公式：**学习随时间变化的出流系数，并通过堰流公式转换为工程需要的流量。
3. **围绕运行工况验证：**除总体误差外，单独检查启闭瞬间以及不同水位、启闭速度下的表现。

6–5–1 网络及上述训练参数是本研究案例的配置。迁移到其他港闸时，应根据当地观测、时间分辨率和运行条件重新训练与验证。
